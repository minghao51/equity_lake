## 4. Traps that cost time here

- **The serial orchestrator branch is the backfill path.** Anything threaded into
  `_finalize_market` must be threaded in *both* branches; a `--lake-dir` regression there sent
  real-root writes to the canonical lake and was invisible to the parallel-branch tests.
- **A `-q` summary line can vanish from a redirect.** Derive the counts instead of trusting the
  tail of the log, or use `--junitxml`.
- **The vendor gives no identity.** `us_equity` rows resolve `mic` only from the exact current
  ticker config (`identity_provenance=current_ticker_config`), so a fetcher built without a
  `TickerConfig` raises `LegacyIdentityUnavailableError`. `backfill` passes one; `ingest` does
  not (finding §3.1).
- **No source-issued action clock exists for yfinance.** `coverage_written=0` is expected, so
  ADR-0015's adjusted read still fails closed on real rows (A06 unchanged). Do not "fix" that
  by synthesizing a proof from ingestion time.
- **A split's own session is already post-split at the vendor.** The factor must use
  `ex_date > row date`, not `>=`; using `>=` inflates the ex-date row too.
- **The raw basis *has* the seam.** "No seam" is a property of the vendor basis. The correct
  post-landing check is: exactly one scale step per in-window split, at that split's ex-date.
- **The real root is not cataloged and Gold is absent by design.** `equity monitor` now reports
  `N/A` for those checks; a *closed historical* slice still legitimately fails Data
  Freshness, so state the expectation with `--max-age-days` (e.g. 800 for a 2024 window)
  rather than "fixing" the check. The canonical root's verdicts are unchanged and pinned
  by test.
- **Never run `equity portfolio migrate --apply` or a wide ingest without an explicit
  instruction**, and never let a real row enter `data/lake/` — the demo lake's coverage proof
  would validate it.
- Reviewer per stage with a formal verdict (`PASS` / `NEEDS-REVISION` / `BLOCKED`), never
  record a verdict you did not receive. Acceptance of a policy ADR is **not** authorization to
  run it.
