are **design artifacts, not contracts**: the source of truth remains the code,
the accepted ADRs and the user guides. Nothing here is published by MkDocs (the
site root is `docs/`), and nothing here is generated by the build.

## Enforcement counterpart

Pictures do not enforce anything. The dashboard IA is kept honest by
`tests/unit/test_dashboard_ia_parity.py`, which pins both renderers' page sets and
labels against one explicit ledger: adding, renaming or dropping a page on one side
fails the suite until it is recorded deliberately. The Streamlit page list is read
from source with `ast`, so a refactor into a shared constant must pass through that
guard too.

## Open decisions recorded by these artifacts

- **Dashboard naming:** standardise the two renderer vocabularies
  (`Dataset Explorer`/`Datasets`, `Update History`/`Updates`) or keep the two voices
  deliberately. Nothing here proposes a fix; the parity guard preserves the current
  state either way.
- **Shared UI components:** the two renderers still have separate vocabularies
  (`st.*` vs the exporter's CSS classes); extracting a shared vocabulary is a
  product change that needs its own approval.
- **E01-6:** approved as a plan only — provenance stays `unknown` until implemented.

## Accuracy rules applied

- Every field, option, number and rule shown was taken from the shipped code, an
  accepted ADR, or the approved plan — nothing was invented.
- Provenance that is still `unknown` is drawn as `unknown` and is correct today;
  the E01-6 diagram marks planned work explicitly as *planned*.
- Anything not built or not authorized carries a `GATED — NOT AUTHORIZED` mark.
- Where a value is genuinely unavailable, the mock shows `unavailable` rather than
  a plausible-looking number.

## Verification performed

Each file is self-contained: XML well-formed, `<title>`/`<desc>` for
accessibility, a `viewBox` plus `width`/`height`, real `<text>` nodes (no outlined
glyph paths), no `<script>`, no `<image>`, no `<foreignObject>`, and no external
references (the only `http` occurrences are the mandatory SVG namespace and, in
the API diagram, the displayed loopback address). Each was rendered headless at
its declared size to confirm layout and that no text is clipped.
